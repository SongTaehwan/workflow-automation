workflow-automation · Mechanized Rules Architecture

FSD 의존 구조와 품질 harness가 서로 다른 시점에서 같은 아키텍처 제약을 방어하는 흐름

아키텍처를 룰로 번역

  • • FSD 레이어 방향과 slice 격리를 boundaries가 검사
  • • public API 외 내부 import를 금지해 결합을 제한
  • • api / model / ui의 책임을 경로별 룰로 고정

로컬 개발 harness

  • • dev overlay는 빠른 피드백 전용
  • • commit은 staged 파일을 자동 교정
  • • push는 CI와 같은 4종 검사를 병렬 실행

권위 있는 최종 판정

  • • CI는 format, lint, test, build를 순서대로 검증
  • • PR 본문은 별도 required-sections job으로 검사
  • • main ruleset이 두 status check를 merge 조건으로 강제
